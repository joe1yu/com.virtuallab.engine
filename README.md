# 虚拟实验引擎

面向多学科自由操作虚拟实验的 Unity Package。操作者不需要遵循固定步骤，
引擎会根据当前权威状态裁决语义操作，并将错误区分为阻断后续实验的严重后果、
影响后续现象的状态偏差，以及仅需即时提示的可恢复问题。

## 设计目标

- 输入层只提交抓取、连接、倾倒、加热等设备无关的语义动作；
- 领域层维护实验对象、物质、关系、过程和事实，不依赖 Unity 表现；
- 应用层通过配置规则裁决动作、记录后果、评估目标并生成提示；
- 表现层消费裁决结果和领域事件，驱动动画、材质、音效与界面；
- 新实验优先通过中文 CSV、单个实验总预制体和共享配方扩展，减少运行时代码；
- 场景只保存课程 ID，编译资产从统一运行时目录自动解析，无需拖拽绑定；
- 编译资产不保存 Unity 对象，资源通过可替换的路径加载接口解析，具体类型由使用方声明；
- 通用标识集中定义，配置协议不依赖中英文词典或版本化内部事件。

内核、模块和课程配置的目标边界见
[《虚拟实验引擎架构边界设计》](Documentation/架构边界设计.md)。
[《边界迁移清单》](Documentation/边界迁移清单.md)。

## 目录结构

- `Runtime/Kernel`：标识、数量、温度和仿真时钟等基础值对象；
- `Runtime/Domain`：实验世界、物质库存、对象关系和持续过程；
- `Runtime/Application`：命令裁决、配置课程、目标、评分、提示和事件流；
- `Runtime/Presentation`：与 Unity 无关的表现规则和效果命令；
- `Tests`：不依赖 Unity 适配器的引擎核心行为与错误路径测试；
- `Samples~/UnityAdapter`：Unity 输入、场景、资源、表现、课程创作工具及对应测试；
- `Samples~/Chemistry`：可复用的化学领域能力，不包含具体课程；
- `Samples~/OxygenCourse`：独立的“氧气的实验室制取与性质”完整课程。

## 安装

在 Unity Package Manager 中选择“Add package from git URL”，填写：

```text
https://github.com/joe1yu/com.virtuallab.engine.git
```

项目最低支持 Unity `2021.3`。核心引擎可以单独使用。需要 Unity 交互时先导入
“Unity 适配器” Sample；需要运行氧气课程时，再依次导入“化学实验”和
“氧气的实验室制取与性质” Sample。

## 新增课程

在菜单 `Virtual Lab > 课程 > 课程配置工作台` 中点击“新建课程”，依次完成课程信息、
实验用品、初始装置、操作与过程、教学与错误、检查与生成六个区域。用品模板会展开标准能力
与操作，课程只需描述差异；编译问题会携带明确的表、记录、列和修复动作。

跨课程共用的能力应放入独立学科 Sample，具体课程只保存对象实例、操作特例、学科过程、
教学、表现和验收。一个实验只配置一个总预制体，全部操作对象作为其中带稳定实体 ID 的
`CourseEntityView` 节点存在，不再为每个对象配置模型预制体。

十表职责和工作台操作见 `Samples~/UnityAdapter/README.md`；化学用品目录扩展见
`Samples~/Chemistry/README.md`；氧气课程的对象绑定与配置说明见
`Samples~/OxygenCourse/README.md`。
