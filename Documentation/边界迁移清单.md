# 边界迁移清单

本文是《架构边界设计》的执行清单，用于冻结现有协议的目标所有者。迁移完成前，类型仍可暂时位于原程序集，但不得继续向错误的所有者增加定义。

## 所有权判定规则

- 内核拥有可复用机制和不变量，不拥有实验学科词汇。
- 模块拥有自己产生、解释和校验的协议标识。
- 课程只引用模块协议并提供实例数据，不声明新的运行时协议。
- 表现层只消费科学事件，不回写权威科学状态。
- Unity 适配层只负责场景输入、空间事实和表现执行。

## 第一阶段冻结规则

从本清单建立起执行以下限制：

1. 不向 `InteractionRelationTypeIds`、`InteractionCapabilityIds`、`InteractionSemanticActionIds` 或事实字段所有者目录增加跨模块协议。
2. 不在 `Runtime` 中增加化学、氧气课程或 Unity 专用引用。
3. 不让 Chemistry 引用 OxygenCourse，也不让 UnityAdapter 的通用运行时引用 Chemistry。
4. 不新增横向动作专用课程列；新配置需求先归入模块参数模式。
5. 迁移产生破坏性变化时一次性修改调用方，不添加 `.vN` 或旧协议分支。

## 提交切分

- 阶段一：迁移清单和程序集依赖守卫。
- 阶段二：模块清单、注册上下文、冻结及冲突校验。
- 阶段三：交互、测量、化学和教学协议迁移。
- 阶段四：组件与选择器创作模型及课程编译器切换。
- 阶段五：氧气课程迁移与行为验收。
- 阶段六：删除旧定义、旧列和临时适配。

## 当前实施状态

- 阶段一已完成：现有定义所有权和生产程序集依赖方向已经冻结。
- 阶段二已完成：运行时模块清单、依赖解析、事实读取器、状态操作、事件投影、持续过程推进器和注册冻结已具备统一入口。
- 课程编译产物已显式记录所需运行时模块；会话创建前会校验模块是否安装，不再由运行环境隐式决定课程能力。
- 阶段三已开始：`StructuredFactField` 只保留通用标识值对象；交互、空间和教学字段已迁入独立程序集；所有调用方直接使用当前所有者，未保留兼容入口。
- 独立交互程序集已建立：动作、能力和关系协议已迁入 `VirtualLab.Interaction`，通用 `Domain` 只保留能力接口与关系机制，调用方均已直接切换且没有兼容入口。
- 交互课程集成已迁移：`VirtualLab.Interaction.Courses` 显式拥有交互事实、关系模式注册和交互世界工厂；最小内核不再隐式安装交互关系。
- 关系所有权已迁移：`RelationKind` 和按名称判断的内核分支已删除；交互与化学模块分别注册稳定关系标识、方向、唯一性、端口和删除约束，课程配置及存档直接保存完整协议标识。
- 通用能力事实已收敛为 `ICapability.CapabilityId`：能力实例自行暴露所属模块声明的稳定标识，Core 不再按运行时类型识别交互能力。
- 能力状态编解码已模块化：运行时模块按 `CapabilityId` 注册状态编解码器，交互模块负责容器容量、连接端口和具体交互能力的恢复，Application 不再识别交互能力类型。
- 教学课程集成已迁移：`VirtualLab.Teaching.Courses` 显式拥有命名教学状态、添加/移除操作、事实读取器和存档编解码器；Core 不再默认安装或解释教学语义。
- 空间课程集成已迁移：`VirtualLab.Spatial.Courses` 显式拥有空间参数键、接触和距离事实及读取器；Unity 只采集数值，Core 不再解释空间参数。
- 测量值对象已迁移：`VirtualLab.Measurement` 独立拥有 `Quantity`、`Unit` 和 `Temperature`；最小 Kernel 只保留实体标识、时钟等执行原语。
- 世界状态扩展契约已建立：模块状态按稳定类型注册，由 `ExperimentWorld` 统一负责事务复制、提交、检查点恢复和实体引用清理；内核不解释扩展状态内容。
- 物质库存已整体迁入 Chemistry：`ExperimentWorld.Matter`、`VirtualLab.Domain.Matter`、内置物质事件投影以及固定 `CourseMatterState` 存档字段均已删除，未保留兼容入口。
- 模块世界状态存档已通用化：Application 和 Infrastructure 只保存 `WorldStateTypeId`、条目类型及字符串字段，化学模块自行安装、捕获、验证和恢复物质库存。
- 统一课程进度已删除：氧气课程只为“已完成气密性检查”“已安全停止加热”等真实过程记忆使用命名状态，不再用 `0/1/10` 编码不同含义；“气路已连通”已经改由当前连接网络派生。
- 关系派生事实已收敛固定、夹持、盖合和连接网络：试管固定、工具夹持、瓶盖、灯帽及气路状态直接读取 Interaction 权威关系，课程共删除十六条重复状态写操作。
- 过程记忆只在权威条件满足后写入：气密性检查要求装置完整连接、导气管入水且操作者手握大试管后观察；倒吸风险存在时不会同时完成“安全停止加热”目标。
- 配方包提供者显式公布模块注册的状态操作 ID，编辑期校验从模块契约汇总协议，不再在课程展开器中硬编码 Teaching 或 Chemistry 操作。
- 初始关系配置契约已贯通：课程用独立的 `初始关系.csv` 声明关系和可选端口；配方包注册其拥有的关系类型，编译器校验类型所有权、实体引用、重复标识和端口成对性。
- 抓取语义会移除来源对象已有的覆盖和容器关系，使“拿起盖子即揭开”“拿起容器内对象即取出”由通用交互关系维护，不再由课程逐对象补写状态。
