# 化学课程用品目录与抽象操作实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 建立“用品类别 → 用品模板 → 能力组件”的化学课程创作入口、设备无关的抽象操作生命周期和职责收敛的新课程表，使作者能在 Unity 工作台完成新课程，并一次性迁移氧气课程、删除旧表读取链路与展示词典。

**架构：** UnityAdapter Editor 拥有通用创作描述符、课程草稿、选择器、表单会话和编译入口，Chemistry 以数据提供用品目录与学科描述；编译器把模板、角色和标签展开为既有规范化课程模型。运行时仅增加通用操作实例、阶段、生命周期和执行方式契约，Chemistry 负责科学状态，UnityAdapter 负责输入观测与表现执行。

**技术栈：** Unity 2021.3.42f1、C#、Unity Editor IMGUI、NUnit/Unity Test Framework、UTF-8 CSV、现有 Recipe/Normalized/Compiled Course 管线。

执行方式收敛为平台通用的“即时”“持续输入”“直接操纵”，集中定义在 `CourseOperationExecutionModeIds.cs`；Chemistry 操作描述符只能选择这些稳定模式，不把“倾倒”“加热”等学科操作写成 Unity 执行器类型。

```csharp
public interface ICourseOperationExecutor
{
    string ExecutionModeId { get; }
    void Execute(SemanticActionRequest request, SemanticActionExecution execution);
}

public sealed class CourseOperationExecutorCatalog
{
    private readonly IReadOnlyDictionary<string, ICourseOperationExecutor> _executors;

    public CourseOperationExecutorCatalog(IEnumerable<ICourseOperationExecutor> executors)
    {
        var values = new Dictionary<string, ICourseOperationExecutor>(StringComparer.Ordinal);
        foreach (var executor in executors ?? throw new ArgumentNullException(nameof(executors)))
        {
            if (executor == null || string.IsNullOrWhiteSpace(executor.ExecutionModeId))
            {
                throw new ArgumentException("执行器及其执行方式标识不能为空。", nameof(executors));
            }

            if (!values.TryAdd(executor.ExecutionModeId, executor))
            {
                throw new InvalidOperationException($"执行方式“{executor.ExecutionModeId}”存在多个执行器。");
            }
        }

        _executors = new ReadOnlyDictionary<string, ICourseOperationExecutor>(values);
    }

    public bool TryGet(string executionModeId, out ICourseOperationExecutor executor) =>
        _executors.TryGetValue(executionModeId ?? string.Empty, out executor);
}
```

目录由启动器收集的执行器实例构造，重复模式直接报错，不使用可变全局静态注册。执行器接收 Start/Observe/Complete/Cancel；无法找到执行器时停止表现并报告配置错误，不回写科学状态。`CourseDirectManipulationController` 删除对动作名称的特判，按执行计划调用“直接操纵”执行器。
