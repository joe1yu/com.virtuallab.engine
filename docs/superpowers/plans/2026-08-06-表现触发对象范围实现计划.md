# 表现触发对象范围实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 让课程作者在 `表现.csv` 中用可选的“触发来源、触发目标”精确限定语义操作的对象组合，并完成氧气课程和 Unity 全量验收。

**架构：** 十表数量不变；UnityAdapter 的草稿契约保存两个可选实体引用，展开器验证后写入既有表现覆盖蓝图，编译器和运行时继续使用现有 `CoursePresentationRuleDefinition` 匹配来源与目标。Unity 手势不进入课程和内核，试管夹只配置抽象的“调整位置”授权。

**技术栈：** Unity 2021.3.42f1、C#、Unity Editor IMGUI、NUnit/Unity Test Framework、UTF-8 CSV、现有 Draft → Blueprint → Normalized → Compiled Course 管线。

---
