# 化学实验 Sample

该 Sample 在通用虚拟实验引擎之上提供可复用的化学能力、反应、过程、配方、
共享知识和课程配置编译器，不包含任何具体课程。

## 使用方式

1. 在 Unity Package Manager 中选择“虚拟实验引擎”。
2. 在 Samples 页签先导入“Unity 适配器”。
3. 再导入“化学实验”。
4. 在自有课程的 `课程.csv` 中选择“化学基础”学科配方包。

需要完整课程时，另行导入相应的课程 Sample。

## 化学用品的八个一级类别

1. 容器与反应器皿
2. 测量仪器
3. 加热与点火设备
4. 支撑与夹持器材
5. 连接与密封器材
6. 操作工具
7. 药品与实验材料
8. 安全、清洁与废弃设施

类别用于帮助作者查找用品，不进入引擎内核的裁决协议。用品能否抓取、夹持、覆盖、连接、
加热或承载物质，由模板所组合的能力组件和抽象操作决定。

## 新增或扩展用品模板

目录位于 `Editor/Authoring/Catalogs`。最常见的新增用品只需要编辑两张表：

1. 在 `用品模板.csv` 添加显示名称、类别、可用操作、建议角色和标签。
2. 在 `模板组件.csv` 组合已有能力并填写默认参数。

只有现有目录无法表达需求时，才继续扩展下列模块表：

- `用品类别.csv`：新增真正可跨课程复用的一级类别；
- `能力组件.csv`：声明新能力、参数模式和语义端口；
- `抽象操作.csv`：声明设备无关操作、生命周期和通用执行方式；
- `科学过程.csv`：声明化学过程及其参数模式；
- `创作选项.csv`：声明关系、事实、表现信号和后果模板；
- `过程编译规则.csv`：把作者可读的科学过程投影为 Chemistry 内部过程命令。

目录值使用自然中文，稳定标识直接由模块注册；不要增加翻译词典。抽象操作只描述“可以做
什么”和生命周期，鼠标、手柄、碰撞与动画由 Unity 适配器实现。若新增内容只属于某一门
课程，应写在课程十表中，不要放进 Chemistry。
