# Unity 适配器 Sample

该 Sample 将与 Unity 直接相关的能力放在核心引擎之外，包括场景对象绑定、空间事实、
语义输入、表现执行、课程资源加载，以及中文课程配置的读取、校验和生成工具。

核心引擎不依赖该 Sample；只有需要 Unity 交互与表现的项目才需要导入它。

## 导入与职责

1. 在 Unity Package Manager 中选择“虚拟实验引擎”。
2. 在 Samples 页签先导入“Unity 适配器”。
3. 再按需导入“化学实验”或具体课程 Sample。

运行时程序集为 `VirtualLab.UnityAdapters`，课程创作程序集为
`VirtualLab.Unity.Authoring`。资源只通过路径加载接口解析，具体资源类型由表现使用方声明，
后续可在不修改课程模型的情况下接入 Addressables。

课程场景采用一个实验总预制体。运行时只实例化该预制体一次，再按其中
`CourseEntityView` 保存的实体 ID 注册全部操作对象；`实验对象.csv` 不保存逐对象模型预制体引用。

## 新建课程的最短路径

打开 `Virtual Lab > 课程 > 课程配置工作台`，点击“新建课程”。工作台创建完整十表后，
按下面六个区域配置即可：

1. **课程信息**：填写课程名称、学科包、操作者和实验总预制体路径。
2. **实验用品**：从学科模块注册的用品类别和模板中添加对象；固定或可移动能力来自模板，
   不靠课程逐条禁用操作。
3. **初始装置**：设置对象位置、旋转以及夹持、覆盖、连接等初始关系。
4. **操作与过程**：通常直接使用模板标准操作；只有本课程与模板默认行为不同时才添加
   操作特例，并在这里配置学科过程。
5. **教学与错误**：分别填写目标、风险严重度、发生后如何继续和受影响目标。严重度不决定
   是否还能继续，两者必须独立配置。
6. **检查与生成**：保存并编译，逐条查看“问题、建议、位置”；点击诊断动作可直接切换到
   对应创作区和配置记录。通过后再生成课程资产。

工作台覆盖日常创建路径。需要批量录入或代码审查时，可以直接编辑高级 CSV；保存后回到
工作台刷新并编译。

## 十张课程职责表

| 表 | 只负责什么 |
| --- | --- |
| `课程.csv` | 课程身份、学科包、操作者、实验总预制体逻辑路径 |
| `实验对象.csv` | 对象实例、用品模板、角色、标签和初始变换 |
| `组件.csv` | 对模板默认能力参数做课程级覆盖 |
| `初始关系.csv` | 对象之间开局已经成立的关系和端口连接 |
| `操作特例.csv` | 对标准操作做允许、拒绝、条件或后果覆盖 |
| `过程.csv` | 学科过程及其主体、来源、目标和参数 |
| `教学.csv` | 教学目标或风险及其提示、评分和继续方式 |
| `教学条件.csv` | 教学项成立所需的可验证事实条件 |
| `表现.csv` | 领域信号到表现协议和逻辑资源参数的映射 |
| `验收场景.csv` | 用动作与断言描述课程可执行的验收路径 |

表名、列名和中文允许值集中在创作协议中。读取器严格按十表处理，不兼容旧表，也不通过
中英文词典或字段猜测修补配置。

## 实验总预制体

- 一个课程只配置一个总预制体路径；所有可操作对象都在该预制体中。
- 每个对象节点挂载 `CourseEntityView`，其实体 ID 必须与 `实验对象.csv` 完全一致。
- 连接端口、受热点、观察点和表现插槽放在相应对象节点下，由编译检查验证。
- 课程资产只保存逻辑加载路径，不保存 Prefab、Material、AudioClip 等 Unity 对象引用。
- 默认加载器可被替换；接入 Addressables 时实现路径加载接口即可，无需修改课程协议。
