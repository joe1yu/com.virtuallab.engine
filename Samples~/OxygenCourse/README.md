# 氧气的实验室制取与性质 Sample

该 Sample 提供课程 CSV、包含全部操作对象的单个实验总预制体、材质、生成资产、演示场景和专项测试，不拥有
通用化学实现。

## 使用方式

1. 在 Unity Package Manager 中先导入“Unity 适配器”Sample。
2. 再导入“化学实验”Sample。
3. 最后导入“氧气的实验室制取与性质”Sample。
4. 执行菜单 `Virtual Lab > 课程 > 编译 > 氧气的实验室制取与性质`。
5. 打开该 Sample 的 `Scenes/OxygenLaboratory.unity` 并运行。

课程 CSV 使用 `课程目录/...` 引用同课程资源，因此导入目录和引擎版本变化后
不需要修改配置表。

## 修改课程

优先打开 `Virtual Lab > 课程 > 课程配置工作台`。本课程的 `Authoring` 目录严格包含：

- `课程.csv`：课程身份和实验总预制体路径；
- `实验对象.csv`、`组件.csv`：31 个对象实例及必要的能力参数覆盖；
- `初始关系.csv`：开局装置关系；
- `操作特例.csv`：仅记录氧气课程不同于模板默认值的操作；
- `过程.csv`：制取、收集和性质验证涉及的化学过程；
- `教学.csv`、`教学条件.csv`：目标、错误后果及其判断条件；
- `表现.csv`：领域信号对应的表现协议和逻辑资源路径；
- `验收场景.csv`：可重复执行的课程验收动作与断言。

修改后先在“检查与生成”区保存并编译。诊断会给出目标表、配置标识、列和修复动作；不要
直接修改 `Generated/氧气实验课程.asset`，它是十表编译结果。

## 实验器材建模

课程中的铁架台、试管架、升降台、水槽和废液缸固定不可移动。试管夹作为独立操作
对象，可沿铁架台上下移动和旋转，并带动被夹住的试管调整高度与倾斜角。酒精灯在
固定升降台上调整位置，而不是移动升降台本体。两块玻璃片与两只集气瓶使用相同的
配对标签，因此任意一块玻璃片都可以覆盖任意一只集气瓶。
连接件拆分为“橡胶塞玻璃导管”和“折角导气管”，只有两段正确连接后才形成完整气路。
带盖试剂瓶、酒精灯及灯帽、试管架与试管、废液缸、火柴、镊子、药匙、坩埚钳、
加水烧杯、集气瓶和玻璃片等器材均作为独立实体参与操作与错误判定。

所有器材都位于一个实验总预制体内，不为每个操作对象保存独立模型预制体引用。
预制体中的每个对象节点通过 `CourseEntityView` 实体 ID 与 `实验对象.csv` 绑定；对象名称、
层级和美术资源可以独立调整，只要稳定实体 ID、语义锚点和表现插槽契约不变。
“木炭”和“组合引燃火柴”是物料或组合器材的内部语义实体，用于反应与状态计算，
不表示额外摆放的一套器材。

“火柴”实体表示火柴盒提供的当前一根火柴。重复将用过的火柴放入废液缸采用幂等关系
记录，使课程可复用同一套消耗品交互配置，而不必按火柴数量复制规则。

生成资产不保存 Prefab、Material、AudioClip 等对象引用；实验总预制体和表现资源都以逻辑
路径交给 Unity 适配器加载。未来切换 Addressables 时，课程表与 Chemistry 规则无需改变。
